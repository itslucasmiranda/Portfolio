## Como o site foi construído

Site estático em **HTML, CSS e JavaScript**, sem framework, instalação de dependências ou etapa de build.

- Layout responsivo com fundo topográfico, tipografia condensada e ilustrações em SVG.
- Animações de entrada, indicador de progresso e interação com o avatar.
- Navegação para dispositivos móveis e blocos expansíveis para detalhes.
- Controle para pausar animações e respeito à preferência `prefers-reduced-motion`.
- Link para pular ao conteúdo, estados ARIA e fechamento do menu pela tecla Escape.
- Publicação com GitHub Pages.

As tecnologias dos projetos apresentados, como Python e FastAPI, pertencem aos respectivos repositórios. Este repositório contém a interface do portfólio.

## Executar localmente

Clone o repositório:

```bash
git clone https://github.com/itslucasmiranda/Portfolio.git
cd Portfolio
```

Abra `index.html` no navegador. Para servir os arquivos localmente, com Python 3 instalado:

```bash
python -m http.server 8000
```

Acesse [http://localhost:8000](http://localhost:8000). As fontes do Google Fonts e o avatar do GitHub dependem de conexão com a internet.
